# Autograph

Autograph is a web application for creating and managing digital signatures.  
The project was developed as part of a software development project, with a focus on modern web technologies, user interface design and practical application of AI-supported development.

## 🚀 Features

- Creating digital signatures
- Managing created signatures
- User-friendly interface
- Responsive design
- Modern and intuitive UI
- Component-based application structure
- AI-assisted development and code analysis

## 🛠️ Technologies

- React
- JavaScript

- HTML5
- CSS3
- Git
- AI development tools
- APIs

## 🎨 Design

The interface and visual concept of the application were designed with a focus on simplicity, readability and ease of use.

## 👨‍💻 Development

The project was developed as part of a team-based software development process.

My responsibilities included:

- Frontend development
- Application structure and components
- UI implementation
- Code analysis and improvements
- Using AI tools to support software development
- Collaboration within the development team

## 🔧 Installation

Clone the repository:

```bash
git clone https://github.com/czeked/Autograph-fcv.git
cd Autograph-fcv
cd frontend
npm install
npm run dev
```
Next, in a second terminal window:
```bash
cd backend
npm install
node index.js
